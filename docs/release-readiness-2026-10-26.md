# v0.17.10 构建前上线评估（2026-10-26）

更新结论：v0.17.10 的 Xray REALITY 客户端兼容回归已复现，暂停继续部署。此前灰度准入结论撤回；等待独立修复版本及现场复测。下文保留原构建评估记录。

2026-10-26 复现：固定依赖的 Xray REALITY 拒绝不含 X25519MLKEM768 的 ClientHello，`minClientVer=0.0.0` 不会绕过检查。独立 sing 客户端、最新 Xray 使用既有 `hellochrome_120` 指纹均失败；新 Xray 默认 chrome 正常。已补足 N2X 实际 Xray 入站的跨客户端握手与内层 HTTPS 回归。两条 freedom.domainStrategy 警告不构成此握手失败原因。

## 已通过的准入检查

- 正式远端依赖下，生产完整标签的 N2X 全项目普通测试、race 与 go vet；模块校验和 tidy 幂等检查。
- 无外网 Linux 容器中的 N2X 全项目测试。测试容器复制当前 conf 源码，覆盖 Linux 文件监听行为；其他源码来自同一构建快照。
- 前一阶段完整迁移的七协议客户端 TCP、Hysteria 1/2 与 TUIC 原生 UDP、并发用户增删、授权撤销、流量归属、sing 入站 REALITY/Vision（未覆盖此次 Xray 入站跨客户端回归）、Naive 浏览器/原生路径、AnyTLS 清理与在线 IP 回归。
- 远端固定版本的源码与本地已验证源码逐文件核对，go mod verify 通过。
- Dockerfile 实际构建与 Linux 双核心版本运行检查；四个 Actions 工作流通过 actionlint。
- 本次新增热重载回归连续五轮 race 通过：分段写入等待安静期、冷却期内的最终修正不会丢失、旧配置在无效更新时继续运行、关闭等待正在进行的重载。旧节流逻辑通过只读源码覆盖复现出修正事件丢失。

最终安装包另由本地构建脚本验证：源码必须干净，模块替换与二进制内固定依赖必须一致，内存保护默认值保持 70%/90%，ZIP CRC、四种摘要和本机双核心版本运行均需通过。安装包对应的 N2X 精确提交、工具链、模块、规则数据和哈希记录在构建生成的 release-manifest.json 中。

## 已完善的发布衔接

- 自动同步只应用已审查的定制核心替换和共享版本；更新核心必须先合并到定制仓库，避免原先的自动同步配置拉回旧依赖或丢失定制功能。
- Docker 排除本地工作区、输出、缓存和环境文件，使用完整生产标签与只读模块构建，并记录版本及源码提交标签。
- CodeQL 显式构建两个核心，发布工作流使用固定模块并检查校验值。
- 新增可重复的本地三架构打包脚本，输出 Linux amd64、arm64、armv7 ZIP 和对应 .dgst，不通过此脚本发布 GitHub Release。
- 修复回归发现的 Xray 并发首流计数器覆盖，以及配置/DNS 热重载丢失最后一次修改的问题。

## 上线边界与观察项

1. **底层自定义 DNS 配置。** OriginalPath 非空且含旧 address 形式 DNS 服务器或旧顶层 dns.fakeip 的节点，需要先按官方 1.14 格式迁移并备份原配置。默认空 OriginalPath 与 N2X 面板节点字段已回归验证；没有自动改写部署配置。
2. **真实网络兼容性。** 灰度观察 REALITY/Vision、ArtX 回落、Naive 浏览器认证、AnyTLS 长连接、QUIC/UDP、上下行统计、在线/离线 IP，以及内存、连接数和重连错误。局部集成测试不能代替长时真实客户端负载。
3. **平台覆盖。** Linux 环境测试使用本机 Docker 平台；三个目标均需交叉构建与 ELF/构建信息检查。其他平台不属于本次安装包交付范围。
4. **Vision 的检查器范围。** 官方公共客户端的 uintptr 写法触发 checkptr；公共客户端 Vision 线协议验证在普通模式执行。本地服务端已修复指针来源并单独经过 race/checkptr 回归，整项目 race 未关闭检查器。

## 灰度与回退

先选择少量节点，在一个节点编号上只运行一套后端。停止旧进程后再替换程序；启动前核对实际配置及 OriginalPath 的 DNS 格式，切换后验证真实客户端、上下行统计与在线状态。核心重启会中断现有连接。

灰度异常时停止新进程，恢复 v0.17.9 程序及切换前的配置后启动。此次没有数据库或持久状态迁移；两个核心保留 `backup/pre-sing-1.14.4-migration-20261026` 本地回退标签，既有远端历史完整保留。

构建产物预定目录：`output/releases/v0.17.10/`。构建门禁完成后的清单以该目录的 `release-manifest.json` 和最终验证记录为准；本报告对应构建前技术评估。
